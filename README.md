# 📊 Data Analysis & Visualization Project

Welcome to a simple yet powerful Python project that showcases data analysis and visualization using the most popular Python libraries. This project follows a clear pipeline from **data loading** ➡️ **cleaning** ➡️ **analysis** ➡️ **visualization** — all crafted with a focus on readability and aesthetic design.

---

## 🧰 Technologies & Libraries Used

| Library     | Purpose                          |
|-------------|----------------------------------|
| `pandas`    | Data manipulation & preprocessing |
| `numpy`     | Numerical operations             |
| `seaborn`   | Statistical data visualization   |
| `matplotlib`| Basic plotting and graphing      |
